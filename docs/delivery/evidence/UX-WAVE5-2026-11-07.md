# UX Wave 5 — Low-impact presentation (UX13–UX16), 2026-11-07

Scope: the last four [UX improvements](../../../specs/ux-improvements/spec.md), decided by the user on 2026-11-06 ([decision log](../../../specs/ux-improvements/spec.md#decision-log)) and started on the user's instruction "start wave 5":

- UX13: cap bar caption size.
- UX14: quieter "No amount" on Details.
- UX15: option B, shrink calendar cells to fit.
- UX16: compact headings in landscape.

All four are presentation-only and governed by [DESIGN](../../DESIGN.md#ux-review-decisions-2026-11-06); no product rule, schema or data changes. All observations are agent-observed on 2026-11-07. Emulator evidence only; the phone still holds a build signed by another computer.

## Environment

Base `d89ce9d` plus the uncommitted working tree (Waves 1–4 and earlier work). Windows 11, .NET SDK 10.0.403, no new packages. Emulator `duewise_api35_default` (Android 35, `google_atd`, 1080 × 2400 at density 420, so 411 dp wide), restarted for this wave; Debug Fast Deployment to `emulator-5554` only, device date 07 Nov 2026. Narrow and landscape screens simulated with `wm size 840x1866` (320 dp) and `wm size 2400x1080`.

New coverage in `LayoutRules`:

- **Captions (UX13):** follow the system up to 130%, shrink only to fit a narrow slot, never below 85%, and have a sensible unmeasured default.
- **Day cells (UX15):** 44 wherever seven fit; 40 at a 292-wide row (320 dp phone); never below 24; 44 before the grid is measured.
- **Headings (UX16):** 20 only when width exceeds height.
- **Amount flag (UX14):** no amount is flagged; zero still counts as an amount.
