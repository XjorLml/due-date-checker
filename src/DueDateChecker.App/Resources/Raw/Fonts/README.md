# Plus Jakarta Sans

Four unmodified static TTF weights (Regular, Medium, SemiBold, Bold) are bundled from [Tokotype's upstream repository](https://github.com/tokotype/PlusJakartaSans/tree/18d1cd2f7ea10481919d2f05c1f7064b7307fc26/fonts/ttf), pinned to commit `18d1cd2f7ea10481919d2f05c1f7064b7307fc26`. Downloaded 2026-10-17 for the authorized design-adoption task.

Copyright and SIL Open Font License 1.1 are preserved in [PlusJakartaSans-OFL.txt](PlusJakartaSans-OFL.txt), bundled as a raw app asset. Fonts remain unmodified and retain their original names. The app loads only local files, with no runtime font network access. Aliases are registered in MauiProgram; typography roles are defined in Resources/Styles/Styles.xaml.
